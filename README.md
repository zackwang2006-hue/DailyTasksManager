# 计划炼金台 ScheduleApp

一个基于 Python + PySide6 开发的桌面任务管理软件，支持短期任务、长期任务、每日任务、附加任务管理，并提供桌面悬浮窗、每日打卡、历史记录、任务置顶、开机自启动等功能。

项目目标是做一个轻量但实用的个人日程管理工具，让任务不只是被记录下来，而是能在桌面上持续提醒、分类展示，并通过打卡和历史记录形成可追踪的完成反馈。

## 功能特点

### 任务管理

* 支持创建、编辑、删除任务
* 支持短期任务、长期任务、每日任务、附加任务分类
* 支持任务描述、截止时间、任务状态管理
* 支持任务置顶显示
* 支持按截止时间进行颜色提示
* 支持任务完成后进入历史记录

### 每日打卡

* 支持每日任务单独管理
* 每日任务可在打卡页面中完成
* 支持每日 00:00 后刷新当日打卡状态
* 支持查看最近打卡情况
* 支持统计连续坚持天数和任务开始时间

### 历史记录

* 支持查看已完成任务记录
* 支持按日期查看历史完成情况
* 支持日历区域与完成记录区域分区显示
* 支持通过分隔条调整上下区域大小

### 桌面悬浮窗

* 支持桌面悬浮任务清单
* 支持显示今日截止、近三日截止、近七日截止、全部任务
* 支持透明度调整
* 支持折叠/展开
* 支持右键菜单
* 支持点击任务查看详情
* 支持任务置顶显示

### 系统托盘与自启动

* 支持最小化到系统托盘
* 支持托盘菜单快速打开主窗口或退出程序
* 支持设置开机自启动
* 开发环境下可通过 Python 脚本路径写入注册表
* 打包为 exe 后可切换为 exe 路径自启动

### 本地数据存储

* 使用 SQLite 本地数据库保存任务数据
* 数据库默认存放在用户本地应用数据目录
* 不依赖网络服务，适合作为个人离线任务管理工具

## 运行环境

建议使用 Python 3.10 及以上版本。

本项目主要面向 Windows 桌面环境开发，部分功能如开机自启动、系统托盘、注册表写入等功能主要针对 Windows 系统。

## 安装与运行

### 1. 克隆项目

```bash
git clone https://github.com/你的用户名/ScheduleApp.git
cd ScheduleApp
```

### 2. 创建虚拟环境

```bash
python -m venv .venv
```

Windows PowerShell 下激活虚拟环境：

```bash
.venv\Scripts\activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

如果没有 `requirements.txt`，也可以先手动安装核心依赖：

```bash
pip install PySide6
```

### 4. 启动程序

```bash
python main.py
```

## 数据存储说明

程序使用 SQLite 作为本地数据库。

数据库文件默认保存在 Windows 本地应用数据目录，例如：

```text
C:\Users\你的用户名\AppData\Local\计划炼金台\schedule.db
```

这样可以避免将用户数据直接写入项目目录，也方便后续打包为 exe 后继续稳定保存数据。

## 开机自启动说明

程序支持在设置页中开启或关闭开机自启动。

开发环境下，自启动注册表项会指向：

```text
python.exe main.py
```

打包为 exe 后，自启动注册表项应指向：

```text
ScheduleApp.exe
```

可通过 PowerShell 检查注册表项：

```powershell
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run"
```

如果启用了开机自启动，应能看到类似：

```text
ScheduleApp    REG_SZ    "...\python.exe" "...\ScheduleApp\main.py"
```

关闭自启动后，该注册表项会被删除。

## 打包说明

项目后续可使用 PyInstaller 打包为 Windows 可执行文件。

示例命令：

```bash
pyinstaller -F -w main.py
```

实际打包时建议根据项目资源、图标、数据库路径和隐藏导入情况进一步完善 `.spec` 文件。

## 项目定位

计划炼金台不是一个追求复杂协作功能的任务管理系统，而是一个偏向个人使用的桌面任务提醒工具。

它更关注以下几点：

* 打开电脑就能看到今天该做什么
* 任务分类清晰，不同类型任务有不同处理方式
* 每日任务可以长期追踪
* 已完成任务能够留下记录
* 悬浮窗能在不打扰使用的情况下持续提醒
