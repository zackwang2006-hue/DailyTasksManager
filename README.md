# ScheduleApp

## 版本记录

### 2.0.1

- 调整悬浮窗贴边半隐藏规则，左侧和右侧边缘任意位置吸附后均可自动收纳，不再仅限角落。
- 优化悬浮窗贴边半隐藏规则，左右边缘仅在角落吸附时自动收纳，避免侧边中部误隐藏。
- 修复顶部半隐藏露出过多的问题，现在仅保留小条区域用于唤出。
- 为悬浮窗自动隐藏和唤出增加平滑移动动画，减少突兀感。
- 新增悬浮窗贴边自动半隐藏功能，吸附到屏幕边缘后可自动收纳，只保留一小部分用于唤出。
- 鼠标移入或点击露出区域时，悬浮窗会自动恢复显示；鼠标离开后延迟再次半隐藏。
- 新增悬浮窗屏幕边缘吸附功能，拖动到屏幕边缘附近松手后可自动贴边。
- 优化悬浮窗位置边界限制，避免窗口被拖出屏幕导致找不回。
